marxistdotcom2epub

Convert books from marxist.com into portable EPUB files with working footnotes.

marxist.com serves its books through a web reader that doesn't allow downloads. If you want to read on an e-reader, this tool gets you the .epub file.

1. Paste a URL

Drop in a link to any book or /read page on marxist.com and download the finished EPUB.

Direct Converter

2. The Bookmarxlet

Prefer to seize the means of EPUB production directly? The Bookmarxlet is a regular browser bookmarklet (a tiny piece of JavaScript saved as a bookmark) that runs straight inside an open marxist.com tab. Because it lives inside the page itself, it needs no proxy server at all.

Drag this button up to your bookmarks bar:

Bookmarxlet: Save EPUB

Next time you have a book's /read page open on marxist.com, click the bookmark and your .epub will download automatically.

3. Terminal Script

If you would rather do this from the command line on Linux, macOS, or BSD, grab the POSIX shell script from the GitHub repository (requires curl, jq, and zip).
